# Bodycam Guide

Independent fan-made SEO guide site for Bodycam searches around Zombies, Trenches, Locked & Loaded, latest updates, and game modes.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Cloudflare Pages

- Build command: `npm run build`
- Output directory: `dist`

The production domain used in canonical URLs, robots.txt, and sitemap.xml is `https://bodycam.website`.
